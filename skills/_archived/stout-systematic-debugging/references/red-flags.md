# Red Flags - PARE E REAVALIE

Se você pensar ou fizer qualquer um destes itens, você está falhando no processo:

1. "Correção rápida por enquanto, investigo depois."
2. "Só vou tentar mudar isso aqui e ver se funciona."
3. "Vou pular o teste, eu verifico manualmente."
4. "Provavelmente é X, deixa eu consertar."
5. "Não entendo bem, mas isso aqui pode resolver."

**Regra de Ouro:** Se você falhar em 3 tentativas de correção, **Questione a Arquitetura**. O problema não é o bug, é o design.
