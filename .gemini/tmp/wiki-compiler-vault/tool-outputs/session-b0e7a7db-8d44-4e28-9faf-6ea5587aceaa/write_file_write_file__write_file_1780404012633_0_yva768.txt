Funcionamento do Motor\r\nO sistema monitora diariamente os horímetros da frota ativa e gera alertas semanais baseados em réguas de desgaste:\r\n- **FPS:** Alerta a cada **+200 horas**.\r\n- **Material Rodante (Tratores):** Alerta a cada **+1.500 horas**.\r\n- **Material Rodante (Escavadeiras):** Alerta a cada **+3.000 horas**.\r\n\r\n## 📊 Governança e Auditoria\r\nA campanha inclui a
