# 🧠 Stout Systematic Debugging (Local Elite)

Esta skill é o protocolo obrigatório para lidar com qualquer comportamento inesperado no sistema. Ela proíbe "tentativas aleatórias" de correção e exige uma abordagem baseada em evidências.

## 🚀 Quando Usar

- Em toda falha de teste ou erro de execução.
- Quando o `stout-immunity-gate` for ativado.
- Se uma correção anterior não funcionou (indica erro de diagnóstico).

## 🛡️ Governanca

- **Iron Law:** Nenhuma correção sem investigação prévia de causa raiz.
- Toda correção deve ser validada via ciclo TDD completo.

## When to Use

Use for ANY technical issue:

- Test failures
- Bugs in production
- Unexpected behavior
- Performance problems
- Build failures
- Integration issues
