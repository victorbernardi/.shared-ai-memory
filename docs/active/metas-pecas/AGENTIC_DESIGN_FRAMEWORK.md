# Agentic Design Framework: Orquestrando Exércitos de IA para Inovação de Produtos

## 1. Filosofia Central: O "Assassino do Figma" (Figma Bypass)
O Agentic Design Framework (ADF) postula que, na era da IA Agentica, a separação entre Design e Código é um gargalo. Projetamos diretamente no meio final com dados reais.

## 2. DNA Visual: Luxury Earthy iOS
A estética deste projeto evoluiu para o **"Luxury Earth"**:
*   **Substrato (Background):** Terra Profunda (#1E1B18). Base orgânica que traz calor e autoridade industrial.
*   **Materialidade:** Liquid Glass (Desfoque de 90px). Vidro denso e premium que flutua sobre o solo.
*   **Hierarquia:** Bento Box Dinâmico. Cards com tamanhos variados conforme a relevância (Mês Atual > Ano).
*   **Acentuação:** Amarelo John Deere (#FFB800) como fonte de luz e Hazard Glows pulsantes.

## 3. Engenharia de Movimento (GSAP & Lottie)
*   **Morphing de Partículas:** O Funil Estratégico desmaterializa-se em uma nuvem de dados que se reorganiza no Gráfico de Vendas via ScrollTrigger (Scrub).
*   **State Machines (Lottie):** Ícones reativos com lógica de estados (Idle, Hover, Click).
*   **Interatividade:** Tooltips dinâmicos ApexCharts que respeitam a profundidade do vidro.

## 4. Fluxo de Trabalho de Implementação
1. **Brainstorming**: DNA Visual e Lock de Indicadores.
2. **Planejamento**: Spec-Driven Rebuild.
3. **Execução**: Construção modular com Snapshots Atômicos.
4. **Auditoria**: Verificação final "Diff Zero" (Paridade Financeira).
