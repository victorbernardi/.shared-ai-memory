# Canonical Control source decision

The canonical versioned source for the Control package is the repository path
`skills/orca-project-control/` in `.shared-ai-memory`. The package is composed
of `SKILL.md` and `references/control-protocol.md`, based on the installed
read-only contract and reconciled with the updated Control contract.

This decision resolves the source/path question for the repository artifact;
it does not claim Run 0 approval, global installation, integration, activation,
publication, or a real pilot. Any later promotion to an installed skills
directory requires a separate accepted gate and explicit authority. The global
`AGENTS.md` remains unchanged.
